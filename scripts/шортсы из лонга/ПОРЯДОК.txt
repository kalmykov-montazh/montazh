Шортсы из горизонтального лонга (слайды + камера в углу). Проба 10.10.2026, «Шортсы ВНЖ после защиты».
Исходник: готовый лонг на скорости 1.2 без наложений (3 скорость 1.2.mp4) -> src.mp4, модель -> model.bin.
1. Распознать весь лонг, выбрать куски 25-45 с, границы по тишине (silencedetect -38dB 0.12 с).
2. shorts.json: seg, title (2 строки), hl, red/green, text = что сказано вслух.
3. layout.py: EXT = правый и нижний край контента слайда для каждого куска (слайд целиком, угол с камерой закрыт).
4. python3 build.py [id...] — DTW-выравнивание слов, субтитры, рендер 1080x1920 60 к/с CRF 15. В конец добавляется «Всё, пошёл работать» из лонга.
5. python3 diffchk.py id — сверка текста субтитров с распознанным.
6. python3 cover.py — обложки (кадр выбрать глазами, секунды в T).
7. parts.py -> device_commit_files, маркеры .parts последними.
