# montazh

Автомонтаж коротких видео (программы монтажа). Видео и доступы здесь не хранятся.

## Новый стиль (с 21.10.2026) — задача «2Н. Смонтировать ролик — новый стиль»

Утверждён Евгением на ролике «ЖИЗНЬ Чаевые в Испании»: субтитры «микс», плашки лесенкой сверху,
надпись в начале, призыв в конце, обложки 7 стилей вперемешку. Скорость 1.2 и плавное кадрирование — прежние.

1. Этап 1 (распознавание) — как раньше.
2. Claude кладёт `novyj/<ключ работы>.json` (пример — `novyj/20261011_194213_1.json`): плашки (`groups`), надпись (`title`),
   призыв (`cta`), слова-акценты (`keys`), высота субтитров (`mix_y`, по умолчанию под подбородком) и обложку
   (`cover`: `style` = yellow / whiteyellow / gold5 / gold / torn / goldpill / ladder или номер 1–7, `top`, `bot`, необязательно `t` — секунда готового ролика).
3. Запуск: `gh workflow run smontirovat-novyj.yml -f src=… -f dest=… -f fixes='{…}' -f pack='…'`.
   «Всё, пошёл работать» выбрасывать через fixes: `{"ключ куска": "субтитр"}`.
4. Результат в папке ролика: `!!! <папка>.mp4`, `обложка.jpg`, `упаковка.txt`; для проверки — `работа/<ключ>/кадры.jpg` (10 кадров) и `кандидаты.jpg` (кадры для обложки).

Скрипты: `scripts/overlay.py` (субтитры и плашки), `scripts/cover_new.py` (обложки, вызывает cover_style.py / gold2.py / cover_text2.py),
`scripts/montage.py` с `NOSUBS=1` (основа без субтитров + `words_out.json`). Шрифты — `fonts/`.
