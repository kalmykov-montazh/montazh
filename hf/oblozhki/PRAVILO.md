## 5 стилей и когда какой
- shapka — ЦВЕТНАЯ ШАПКА, ОСНОВНАЯ. Верх кадра залит цветом до макушки. С 14.11.2026 (Евгений 22:55, «вариант 3»): шапка только КРАСНАЯ #e3191c или СИНЯЯ #1d5fd1, чередуются по порядку роликов в novyj; top — жёлтая строка (Unbounded 112, не меньше 76) с жёлтыми чёрточками по бокам «— 5 РАЙОНОВ —», без плашек; bot — крупная ЖЁЛТАЯ #ffd400 с мягкой тёмной тенью. Чёрный текст на цветной шапке и чёрные плашки — НЕ ставить (не читается / некрасиво)
- spina  — ТЕКСТ ЗА СПИНОЙ. Громкие темы одним словом: дети, налог, штраф, отказ, запрет, выселение, пенсия. Огромное слово cover.word за головой, фигура поверх (rembg ставится сам при первом таком ролике). top — жёлтая плашка на груди, bot — строка «от руки»
- hormozi — СТИЛЬ ХОРМОЗИ. Советы, документы, деньги, «как сделать». top белая, первая часть bot на зелёной плашке, остаток bot мелко
- novost — НОВОСТНАЯ МОЛНИЯ. Все новости. Метка cover.label (по умолчанию «ВАЖНО», можно «НОВОСТЬ»), тёмная полоса на груди: top белая, bot жёлтая
- chb    — Ч/Б + КРАСНОЕ СЛОВО. Личные истории, хронология, переезд. top белая над головой, bot крупно красным

## Поля в novyj/<ключ>.json → "cover"
- top, bot — как раньше (в bot части через «|»)
- s5 — стиль: shapka / spina / hormozi / novost / chb. Если не задан: тег НОВ → novost, ПУТЬ/ХРОН → chb, задан word → spina, иначе shapka
- word — одно слово для «текста за спиной»
- label — метка новости
- color — свой цвет шапки (иначе с 14.11.2026 красный/синий по очереди; цвета рубрик для шапки больше не используются)

Выбор стиля под ролик делает Claude по смыслу при записи novyj: обычная тема — shapka; есть одно громкое слово — spina; совет/документы/деньги — hormozi; новость — novost; личная история — chb. Подряд в ленте разные.

## Общие правила
Текст никогда на лице и голове, весь текст в полосе y 300–1450 (сетка 3:4 срезает по 240 px), главное слово крупно, по ширине кадра. Кадр: глаза открыты и спокойные, рот закрыт. Цифры и € — в роликах про штрафы, суммы, сроки.
Образцы: Google Диск «Монтаж!/Брокер/Обложки — пробы 11.11» (15, 35, 21, 03, 23).
